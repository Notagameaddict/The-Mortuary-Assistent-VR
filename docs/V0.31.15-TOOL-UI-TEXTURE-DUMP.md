# v0.31.15 — Tool UI texture dump

v0.31.14 confirmed that premultiplied alpha did not change the remaining
visual artifacts. Rather than continue changing composition parameters, this
diagnostic build captures exactly what is being sent to OpenXR.

On the first visible CircleRet frame it writes two 32-bit TGA files:

```text
BepInEx/plugins/MortuaryAssistantVR/ToolUiSource-v0.31.15.tga
BepInEx/plugins/MortuaryAssistantVR/ToolUiOpenXR-v0.31.15.tga
```

`ToolUiSource` is the Unity RenderTexture before the native shader.
`ToolUiOpenXR` is the OpenXR swapchain texture after the native copy/shader.

The TGA files preserve alpha. Comparing them will tell us whether the
black/blue right strip is already present in Unity, introduced by the native
copy, or appears only later in the OpenXR compositor/headset.

## Replace

- `PluginInfo.cs`
- `XR/D3D11PresentHookProbe.cs`
- `XR/OpenXrNativeBackend.cs`
- `native/PresentHookProbe/PresentHookProbe.cpp`

## Native rebuild required

Rebuild the D3D11 Present Hook Probe and replace its DLL, then rebuild the
managed solution and replace `MortuaryAssistantVR.dll`.

Open the tool menu once, wait a second, close the game, and send both `.tga`
files plus `LogOutput.log`.
