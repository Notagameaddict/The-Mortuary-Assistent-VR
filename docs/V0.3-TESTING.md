# v0.3 Camera Probe test

This milestone does not enable VR yet. It captures the exact gameplay-camera hierarchy and components needed for the first XR rig.

## Install

1. Replace:
   - `Config/ModConfig.cs`
   - `Core/RuntimeBehaviour.cs`
   - `PluginInfo.cs`
2. Add:
   - `Diagnostics/CameraProbe.cs`
3. Keep the existing:
   - `Diagnostics/SceneExplorer.cs`
   - `Diagnostics/RuntimeDiagnostics.cs`
4. Rebuild the solution.
5. Copy the new DLL to:
   - `BepInEx/plugins/MortuaryAssistantVR/`

## Test

1. Start the game.
2. Load a shift and wait at least five seconds after you can move.
3. Walk around briefly.
4. Exit normally.
5. Open `BepInEx/LogOutput.log`.

Search for:

```text
=== Camera Probe begin
[CameraProbe]
=== Camera Probe end
```

Upload the log section for the `Mortuary` scene and any later `Apartment` additive scene.

## Expected result

The probe should identify:

```text
Player/CamHelper/Camera
```

and report components on:

- Camera
- CamHelper
- Player

Those component names will determine where head tracking and body rotation should attach.
