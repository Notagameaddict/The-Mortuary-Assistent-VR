# v0.17.3.4 — IL2CPP camera delegate conversion

The generated IL2CPP `Camera.CameraCallback` wrapper constructor accepts an
`IntPtr`, so constructing it directly from a method group caused CS1503.

This revision uses Il2CppInterop's delegate converter:

```csharp
DelegateSupport.ConvertDelegate<Camera.CameraCallback>(
    new Action<Camera>(OnCameraPreRender))
```

## Replace

- `PluginInfo.cs`
- `Core/RuntimeBehaviour.cs`

No native DLL rebuild is required.

## Expected build result

```text
1 succeeded, 0 failed
```
