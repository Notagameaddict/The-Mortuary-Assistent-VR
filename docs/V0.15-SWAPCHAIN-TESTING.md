# v0.15 — Stereo color swapchains

This milestone queries the runtime's PRIMARY_STEREO view configuration, enumerates supported D3D11 swapchain formats, and creates one color swapchain for each view.

It still submits zero composition layers, so the headset remains blank.

## Replace

- `PluginInfo.cs`
- `XR/OpenXrNativeBackend.cs`
- `XR/XrBackendState.cs`

No native Present-hook rebuild is required.

## Test

1. Rebuild Solution.
2. Copy the rebuilt `MortuaryAssistantVR.dll`.
3. Keep `[XR] AttemptStartup = true`.
4. Connect the headset through Virtual Desktop.
5. Start the game and remain at the main menu for 10–15 seconds.
6. Close the game and upload the complete BepInEx log.

Expected lines:

```text
Loading [MortuaryAssistantVR 0.15.0]
View configuration count result=0, count=2
View[0]: recommended=...
View[1]: recommended=...
Supported swapchain formats: ...
Selected swapchain format ...
xrCreateSwapchain view=0, result=0
xrCreateSwapchain view=1, result=0
state=FrameLoopActive
```

This milestone creates and destroys swapchain handles only. It does not enumerate their D3D11 textures or submit a projection layer.
