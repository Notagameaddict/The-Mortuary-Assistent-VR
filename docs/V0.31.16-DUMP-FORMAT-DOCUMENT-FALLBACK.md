# v0.31.16 — dump format fix + document inspection fallback

The v0.31.15 log showed two new facts.

## Texture dump

Both TGA dumps failed with result 41. That means the underlying D3D11
resources use a typeless RGBA/BGRA DXGI format, even though the OpenXR
swapchain was requested as format 29.

The dumper now accepts:

- R8G8B8A8_TYPELESS / UNORM / UNORM_SRGB
- B8G8R8A8_TYPELESS / UNORM / UNORM_SRGB

If another format is encountered, the numeric DXGI format is returned in the
log.

## Paper/note inspection

The log shows the interaction ray targeting `Note_1`, but no full UI fallback
was activated. The game can therefore enter its document-reading state while
the VR mod keeps the desktop gameplay camera disabled. That explains seeing
neither the paper nor a usable way back.

When a target name contains Note/Paper/Document/Letter/Clipboard and it is
clicked, v0.31.16 activates the existing desktop/cinema UI fallback.

Press Escape or right mouse to release the document fallback and return to
stereo gameplay.
