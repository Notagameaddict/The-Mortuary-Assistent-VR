# v0.2 Scene Explorer test

1. Replace the three existing source files with the versions in this package.
2. Add `Diagnostics/SceneExplorer.cs` to the project folder.
3. Rebuild the solution.
4. Copy the new DLL to `BepInEx/plugins/MortuaryAssistantVR/`.
5. Start the game.
6. Enter the main menu, then start or load a playable shift.
7. Walk around for about one minute.
8. Exit normally.
9. Open `BepInEx/LogOutput.log`.

Search for:

```text
=== Scene Explorer begin
[SceneExplorer]
=== Scene Explorer end
```

The default limit is 1,500 objects per scene. It can be changed in:

```text
BepInEx/config/com.notagameaddict.mortuaryassistantvr.cfg
```

Recommended first gameplay test values:

```ini
[SceneExplorer]
Enabled = true
LogComponents = true
MaxDepth = 8
MaxObjects = 1500
```

Upload the resulting log. The most useful section begins at the first gameplay scene load and ends at the corresponding Scene Explorer end marker.
