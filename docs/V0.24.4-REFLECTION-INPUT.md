# v0.24.4 — Reflection-based legacy mouse input

Visual Studio reported:

```text
CS0103: The name 'Input' does not exist in the current context
```

`UnityEngine.Input` is defined in `UnityEngine.InputLegacyModule.dll`, which
is not referenced by the project.

This revision resolves `UnityEngine.Input` from the game's loaded assemblies
and invokes:

```text
Input.GetMouseButtonDown(int)
```

through reflection.

## Replace

- `PluginInfo.cs`
- `XR/InteractionPromptDetector.cs`

No native rebuild is required.
