# v0.31.4 — Neutral UI camera and visible cursor

The v0.31.3 log confirms that CircleRet isolation itself is stable:

```text
CircleRet isolated on capture layer 30
screen=2560x1440, capture=2560x1440
CircleRet stereo UI capture active
```

The remaining location-dependent blur/black background strongly suggests that
the dedicated UI camera is still inheriting HDRP/environment state from the
gameplay camera. Indoor and outdoor locations use different HDRP volumes,
exposure and other camera effects.

## Changes

### Neutral UI camera

The tool UI camera is moved to a neutral world position far away from local
mortuary volumes. It no longer follows the player's indoor/outdoor location.

The code also looks for HDRP `HDAdditionalCameraData` on the UI camera and
disables version-compatible optional camera effects where possible.

### Visible cursor

The native raw UI blit used by the OpenXR tool-menu quad previously disabled
the cursor deliberately (`stereoEyeIndex == -2`).

v0.31.4 now reads the real Windows cursor position for the UI quad and draws a
small white/black cross at that position.

The cursor shader now also writes alpha, so the cursor remains visible even
over fully transparent areas of the UI RenderTexture.

The world interaction reticle stays disabled while the tool menu is open.
