# v0.31.6 — Explicit transparent tool-UI clear

v0.31.5 proved that the background is not caused by `InGameUI`/`Rsystem`
ancestors: only the `CircleRet` subtree is now on the capture layer, yet a
black background remains indoors and a blue background remains outdoors.

That points to the UI RenderTexture/camera background itself.

v0.31.6 changes the capture path so the tool camera does **not** clear its own
color buffer. Instead the mod explicitly clears the 2560x1440 RenderTexture to:

```text
RGBA = (0, 0, 0, 0)
```

every frame immediately before UI rendering.

This avoids HDRP/environment-dependent camera background clears and gives the
OpenXR source-alpha quad a deterministic transparent background.

The visible cursor and item selection from v0.31.4+ remain unchanged.

## Replace

- `PluginInfo.cs`
- `XR/StereoCameraRig.cs`

No native probe rebuild is required. Keep the v0.31.4 PresentHookProbe DLL.
