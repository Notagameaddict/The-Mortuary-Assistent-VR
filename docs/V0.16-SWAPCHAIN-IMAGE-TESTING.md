# v0.16 — D3D11 swapchain image enumeration

This milestone enumerates the native `ID3D11Texture2D*` images owned by each OpenXR color swapchain.

A small `OpenXrSwapchainImageSet` component now stores the per-view metadata and texture pointers. This begins separating swapchain data from the main backend without changing the proven session lifecycle.

No textures are acquired, written, or submitted as projection layers yet, so the headset remains blank.

## Replace/add

Replace:

- `PluginInfo.cs`
- `XR/OpenXrNativeBackend.cs`
- `XR/XrBackendState.cs`

Add:

- `XR/OpenXrSwapchainImageSet.cs`
