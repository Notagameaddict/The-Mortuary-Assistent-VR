# v0.29 — Tool-menu UI probe

This diagnostic build identifies which Unity object hierarchy contains the
right-mouse tool/inventory menu.

It does not add a new UnityEngine.UI compile-time dependency. Instead it walks
the active Mortuary scene hierarchy and looks for objects whose names or
component type names resemble UI.

## What happens on right mouse

A baseline is maintained while the right mouse button is not held.

When RMB is pressed, snapshots are captured approximately:

```text
+0.05 s
+0.20 s
+0.50 s
+1.00 s
```

Objects that become active, disappear, or are newly created are logged with:

- full hierarchy path;
- `activeSelf`;
- `activeInHierarchy`;
- layer;
- all attached component type names.

If no activation delta is visible, the probe logs the highest-scoring active
UI candidates instead.

A final active-candidate snapshot is logged when RMB is released.

## Test procedure

1. Rebuild Solution.
2. Replace `MortuaryAssistantVR.dll`.
3. Enter Mortuary.
4. Do not open the menu for 2–3 seconds.
5. Press and hold right mouse for about 1.5 seconds.
6. Keep the tool menu visible for another second.
7. Release/close it.
8. Repeat once if convenient.
9. Exit the game and send the new `LogOutput.log`.

Searchable log prefix:

```text
[ToolMenuProbe]
```

The most useful lines will be `NEW ACTIVE`, `ACTIVE CHANGE`, or
`ACTIVE CANDIDATE`.
