# v0.31.1 — Direct Canvas access fix

v0.31 detected CircleRet correctly, but runtime capture failed because:

```text
Canvas reflection API incomplete on 'UnityEngine.Component'
```

The IL2CPP string overload `GetComponent("Canvas")` returns a base
`UnityEngine.Component` wrapper, so normal reflection cannot see Canvas
properties.

v0.31.1 uses strongly typed Unity Canvas access:

```csharp
var canvas = inGameUi.GetComponent<Canvas>();
canvas.renderMode = RenderMode.ScreenSpaceCamera;
canvas.worldCamera = toolUiCamera;
```

This requires `UnityEngine.UIModule.dll` as a project reference.

Typical BepInEx IL2CPP location:

```text
<The Mortuary Assistant>\BepInEx\interop\UnityEngine.UIModule.dll
```

If Visual Studio reports `Canvas` or `RenderMode` as unknown, add this DLL to
the MortuaryAssistantVR project references and rebuild.

The native PresentHookProbe from v0.31 is unchanged and can be kept.
