# v0.22 — Experimental stereo Unity camera prototype

This milestone replaces the cinema quad in gameplay with two off-screen Unity
cameras:

- left eye at -0.032 m;
- right eye at +0.032 m;
- 1600 x 1728 render texture per eye;
- prototype FOV of 92 degrees.

The native Present bridge copies each Unity eye texture into its matching
OpenXR swapchain and submits a stereo projection layer using the runtime's
actual OpenXR eye poses and FOV values.

Outside gameplay scenes, the stable v0.19 cinema quad remains the fallback.

## Test

1. Commit and push the native source.
2. Run `Build D3D11 Present Hook Probe`.
3. Replace the native probe DLL.
4. Rebuild Solution.
5. Replace the managed plugin DLL.
6. Enter the Mortuary scene.

Expected log:

```text
Loading MortuaryAssistantVR v0.22.0
[StereoRig] Prototype eye cameras created
[PresentHookProbe] Set stereo sources result=0
state=StereoPrototypeRendering
status='OpenXR stereo camera prototype is active.'
```

## Important warning

This is the first true stereo experiment, not a production render path.
The game uses HDRP, and the newly created cameras do not yet copy every
HDAdditionalCameraData setting from the gameplay camera. Possible results
include missing post-processing, wrong lighting, black eyes, double rendering,
low performance, incorrect scale, or discomfort.

If the stereo path fails, leaving the Mortuary scene clears the registered eye
textures and returns to the stable cinema quad.
