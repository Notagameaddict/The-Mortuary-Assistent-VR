# v0.30 — CircleRet deep probe

v0.29 identified the tool-menu hierarchy as:

```text
InGameUI/Rsystem/CircleRet
  HolderL/itemSlot
  HolderR/itemSlot
```

However, v0.29 scanned the entire Mortuary scene every 0.5 seconds and again
during RMB snapshots. That diagnostic work can create frame-time spikes and
therefore visible VR judder.

v0.30 removes the broad scene scan.

It resolves only:

```text
InGameUI/Rsystem/CircleRet
```

once, then captures only that small subtree when RMB is pressed.

The probe logs changes in:

- activeSelf / activeInHierarchy;
- local position;
- local scale;
- local Euler rotation;
- component count;
- CanvasGroup alpha;
- CanvasGroup interactable;
- CanvasGroup blocksRaycasts.

Snapshots occur at:

```text
+0.05 s
+0.20 s
+0.50 s
```

There is no continuous 0.5-second full-scene baseline scan.

## Replace

- `PluginInfo.cs`
- `XR/ToolMenuUiProbe.cs`

No native probe rebuild is required.

## Test

1. Rebuild Solution.
2. Replace MortuaryAssistantVR.dll.
3. Enter Mortuary.
4. Wait a few seconds.
5. Press/hold RMB for about one second.
6. Release it.
7. Repeat once.
8. Send the resulting LogOutput.log.

Useful log prefix:

```text
[CircleRetProbe]
```
