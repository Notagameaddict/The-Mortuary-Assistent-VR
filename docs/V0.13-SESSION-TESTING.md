# v0.13 — First OpenXR D3D11 session

This milestone calls `xrCreateSession` after the Present hook captures and validates Unity's real `ID3D11Device`.

It deliberately does not call `xrBeginSession`, create reference spaces, create swapchains, or submit frames.

## Replace

- `PluginInfo.cs`
- `XR/OpenXrNativeBackend.cs`
- `XR/XrBackendState.cs`

The native Present-hook DLL does not need to be rebuilt.

## Test

1. Rebuild Solution.
2. Copy the rebuilt `MortuaryAssistantVR.dll`.
3. Keep `MortuaryAssistantVR.PresentHookProbe.dll` in the game root.
4. Keep `[XR] AttemptStartup = true`.
5. Connect Virtual Desktop and the headset.
6. Start the game and wait at the main menu for at least ten seconds.
7. Close the game and upload the complete BepInEx log.

Expected success:

```text
Loading [MortuaryAssistantVR 0.13.0]
Present-hook comparison: adapterMatches=True, featureLevelMatches=True
Calling xrCreateSession with D3D11 device=0x...
xrCreateSession result=0, session=0x...
state=SessionCreated
```

At shutdown, a successful test may also show:

```text
xrDestroySession result=0
```

## Safety

If the game crashes during session creation, temporarily set:

```ini
[XR]
AttemptStartup = false
```

and keep the crash log. No frame loop is started in this milestone.
