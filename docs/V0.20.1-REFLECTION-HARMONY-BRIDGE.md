# v0.20.1 — Reflection-based Harmony bridge

The project did not reference HarmonyLib at compile time, which caused:

```text
CS0246: The type or namespace name 'HarmonyLib' could not be found
```

This revision removes the compile-time `using HarmonyLib` dependency.
It locates the Harmony runtime types already loaded by BepInEx and invokes
the patch API through reflection.

## Replace

- `PluginInfo.cs`
- `XR/HeadTrackingPatch.cs`

All other v0.20 files remain unchanged.

No native probe rebuild is required.
