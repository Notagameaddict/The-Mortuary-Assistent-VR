# v0.27.2 — Right-mouse tool menu fallback

The right-mouse tool/inventory menu is another screen-space UI layer. It is
not rendered into the two off-screen stereo eye textures.

The v0.27.1 log confirms that non-PC UI only triggered the desktop fallback
when the game actually paused. The tool menu itself does not reliably pause
the game or expose a Unity cursor, so the previous PC-specific UI detector
does not see it.

This revision detects the Windows right mouse button directly with
`GetAsyncKeyState(VK_RBUTTON)`.

While the right mouse button is held:

- the original desktop gameplay camera is enabled;
- stereo source textures are disconnected;
- OpenXR shows the desktop/cinema output containing the game's normal tool
  menu.

The existing 0.75-second release delay remains active, so a quick click still
keeps the menu visible long enough for the UI transition. Releasing the menu
returns to true stereo automatically.

## Replace

- `PluginInfo.cs`
- `XR/StereoCameraRig.cs`

No native probe rebuild is required.

## Expected log

When pressing the right mouse button:

```text
[StereoRig] UI fallback active; paused=False, ..., rightMouse=True. Using desktop/cinema output for screen-space UI.
```

After releasing it:

```text
[StereoRig] UI fallback ended; stereo eye textures restored.
```
