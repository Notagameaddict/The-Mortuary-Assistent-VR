# v0.7 XR backend foundation

This milestone restructures the mod around an XR backend abstraction.

It does **not** yet create an OpenXR instance, session, swapchain, or headset pose. It safely checks whether an application-local OpenXR loader can be loaded and whether `xrGetInstanceProcAddr` can be resolved.

## Replace

- `Config/ModConfig.cs`
- `Core/RuntimeBehaviour.cs`
- `PluginInfo.cs`

## Add

- `XR/IXrBackend.cs`
- `XR/XrBackendState.cs`
- `XR/XrBackendManager.cs`
- `XR/OpenXrNativeBackend.cs`

Keep all existing XR and diagnostics files.

## Important

Do not download a random `openxr_loader.dll`.

For the first build test, leave the loader absent. The expected backend state is:

```text
LoaderUnavailable
```

That confirms the new architecture works without changing game behavior.

## Build and install

1. Rebuild the solution.
2. Confirm `1 succeeded, 0 failed`.
3. Copy the new DLL to:

```text
BepInEx/plugins/MortuaryAssistantVR/
```

4. Keep this config value false:

```ini
[XR]
AttemptStartup = false
```

## Test

Start the game and load a shift. Search the log for:

```text
Loading [MortuaryAssistantVR 0.7.0]
=== XR Backend initialization begin
[XRBackend]
=== XR Backend initialization end
```

Expected without a loader:

```text
state=LoaderUnavailable
```

Upload the resulting log.
