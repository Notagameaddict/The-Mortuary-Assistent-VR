# v0.6 Render Pipeline Probe

This version records the render-pipeline asset and detailed gameplay-camera settings needed before stereoscopic rendering is attempted.

It does not start OpenXR and does not render to the headset.

## Replace

- `Config/ModConfig.cs`
- `Core/RuntimeBehaviour.cs`
- `PluginInfo.cs`

## Add

- `Diagnostics/RenderPipelineProbe.cs`

Keep all existing XR and diagnostics files.

## Build

Rebuild the solution. If Visual Studio reports that `UnityEngine.Rendering` or `GraphicsSettings` cannot be found, verify that the project references:

```text
BepInEx/interop/UnityEngine.CoreModule.dll
```

The probe intentionally avoids a compile-time reference to HDRP-specific classes. HDRP components are discovered through their component type names.

## Test

1. Copy the rebuilt DLL to `BepInEx/plugins/MortuaryAssistantVR/`.
2. Start the game.
3. Load a playable Mortuary shift.
4. Look around and interact briefly.
5. Exit normally.
6. Open `BepInEx/LogOutput.log`.

Search for:

```text
Loading [MortuaryAssistantVR 0.6.0]
=== Render Pipeline Probe begin
[RenderProbe]
=== Render Pipeline Probe end
```

Upload the log.
