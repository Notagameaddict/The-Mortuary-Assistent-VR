# v0.21 — Head position tracking

This milestone keeps the working v0.20.1 rotation tracking and adds relative
headset position tracking.

The first valid OpenXR pose in the Mortuary scene becomes the positional
baseline. Later headset movement is applied as a local offset to:

```text
MortuaryAssistantVR_Head
```

Using a baseline prevents the OpenXR LOCAL-space standing height from moving
the gameplay camera several metres when tracking starts.

Coordinate conversion:

```text
OpenXR (x, y, z) -> Unity (x, y, -z)
```

## Replace

- `PluginInfo.cs`
- `XR/HeadTrackingPatch.cs`

All other v0.20.1 files remain unchanged.

No native probe rebuild is required.

## Test

1. Rebuild Solution.
2. Copy the rebuilt `MortuaryAssistantVR.dll`.
3. Connect Virtual Desktop.
4. Enter the Mortuary scene.
5. Keep your head still for a moment when the scene loads.
6. Lean slowly left/right, forward/backward, and up/down.

Expected log:

```text
Loading MortuaryAssistantVR v0.21.0
[HeadTracking] Position baseline captured: ...
[HeadTracking] Applied pose 1: ..., localPosition=(...)
```

## Expected behaviour

- Rotation should remain smooth and correctly directed.
- Leaning should translate the gameplay camera by the same physical amount.
- Walking with the game controls still moves the Player object normally.

The cinema quad remains the display path; this is still monoscopic rather than
true stereo VR.
