# v0.17.3.2 — Camera render callback

The v0.17.3.1 log showed that Unity never called the injected `LateUpdate()`
method. No test frames were submitted after the session entered RUNNING.

This revision registers the long-standing built-in render callback:

```csharp
Camera.onPreRender
```

The main menu has multiple cameras, so the code uses `Time.frameCount` to
submit at most one OpenXR frame per Unity frame.

## Replace

- `PluginInfo.cs`
- `Core/RuntimeBehaviour.cs`

Keep the other v0.17.3 files. No native probe rebuild is required.
