# v0.30.1 — IL2CPP CanvasGroup probe fix

v0.30 failed to compile with:

```text
CS1503: cannot convert from 'System.Type' to 'Il2CppSystem.Type'
```

The probe no longer calls `GameObject.GetComponent(System.Type)`.
It now enumerates `GetComponents<Component>()`, finds CanvasGroup by runtime
type name, and reflects its properties from that actual component instance.

## Replace

- `PluginInfo.cs`
- `XR/ToolMenuUiProbe.cs`

No native probe rebuild is required.
