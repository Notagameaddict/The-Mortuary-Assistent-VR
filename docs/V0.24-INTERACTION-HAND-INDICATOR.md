# v0.24 — VR interaction hand indicator

The game's normal interaction-hand prompt is a screen-space UI element, so it
is not present in the two off-screen stereo eye textures.

This revision reads likely interaction-state members from the existing
`PlayerInteraction` component. When an interactable target is detected, the
native stereo shader draws a high-contrast hand symbol at the centre of both
eyes.

The detector searches boolean and object members with names such as:

```text
interact
usable
hover
target
focus
selected
current
```

It logs the discovered candidate members and the member that activates the
indicator. This makes the heuristic adjustable if the first test selects the
wrong state.

## Native rebuild required

1. Commit and push the updated native source.
2. Run `Build D3D11 Present Hook Probe`.
3. Replace the native probe DLL.
4. Rebuild Solution.
5. Replace the managed plugin DLL.

## Expected log

When the gameplay scene loads:

```text
[InteractionPrompt] PlayerInteraction found; candidateMembers=...
[InteractionPrompt] Candidate members: ...
```

When looking at an interactable object:

```text
[InteractionPrompt] Active member='...'
[InteractionPrompt] VR hand indicator shown.
```

When looking away:

```text
[InteractionPrompt] VR hand indicator hidden.
```

## Expected headset result

A white hand symbol with a black outline appears at the centre of the VR view
while an interactable object is targeted. The existing mouse cursor and pause
menu fallback remain unchanged.
