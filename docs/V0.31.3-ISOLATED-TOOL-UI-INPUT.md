# v0.31.3 — Isolated CircleRet rendering and input protection

The v0.31.2 log confirms exact 2560x1440 capture and stable stereo UI frames.
The remaining context-dependent black/blur background is most likely unrelated
InGameUI content being captured together with CircleRet.

v0.31.3 temporarily moves only the InGameUI root, the ancestor chain to
CircleRet, and the CircleRet subtree to private layer 30. The tool UI camera
renders only layer 30, excluding unrelated dimmers, blur panels and other HUD
content.

While CircleRet is visible, the world interaction detector is also suspended.
That prevents a tool-menu click from simultaneously triggering the mod's
world-object pickup/use fallback.

## Replace

- `PluginInfo.cs`
- `XR/StereoCameraRig.cs`
- `XR/InteractionPromptDetector.cs`

No native probe rebuild is required.
