# v0.24.5 — Single interaction reticle

The hand icon was drawn independently into both eye images. Because it was a
large flat symbol at zero disparity, it could appear as two hands instead of
one fused indicator.

This revision replaces the hand with a small centred VR reticle:

- thin white ring;
- centre dot;
- short cross lines;
- black outline for contrast.

The compact symmetrical shape is much easier for both eyes to fuse into one
indicator and clearly shows the exact aiming point.

The reflected legacy mouse-input fallback has also been removed. Object pickup
already works through the game's normal input path, while the reflected
`Input.GetMouseButtonDown` call generated repeated exceptions.

## Replace

- `PluginInfo.cs`
- `XR/InteractionPromptDetector.cs`
- `native/PresentHookProbe/PresentHookProbe.cpp`

## Build

The native probe must be rebuilt. After replacing the native DLL, rebuild the
managed solution and replace `MortuaryAssistantVR.dll`.

## Expected result

When an object is targeted, one small circular reticle appears at the centre of
the VR view. Looking away hides it. Doors and pickup interactions continue to
use the game's normal controls.
