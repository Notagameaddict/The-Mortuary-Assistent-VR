# v0.31.5 — CircleRet-only capture layer

v0.31.4 fixed cursor visibility and selection, but the menu background still
varied by location:

- indoors: black, blurred background;
- outdoors: blue-ish background.

The latest log confirms that stereo capture itself remains stable. It also
shows no `Neutralized HDRP camera data` message, so the location-dependent
background is unlikely to be fixed by moving the capture camera.

The more likely cause is v0.31.3's layer isolation. That code moved not only
`CircleRet`, but also its ancestors:

```text
InGameUI
Rsystem
CircleRet
```

If `InGameUI` or `Rsystem` has a full-screen Graphic/material, moving those
objects onto the private capture layer makes that background render into the
tool-menu texture too. This can explain the opaque black/blue and blur-like
appearance.

v0.31.5 moves only:

```text
InGameUI/Rsystem/CircleRet
```

and its descendants to layer 30.

`InGameUI` and `Rsystem` remain on their normal layer and therefore cannot
contribute full-screen graphics to the tool-menu capture camera.

The visible native cursor from v0.31.4 is retained.

## Replace

- `PluginInfo.cs`
- `XR/StereoCameraRig.cs`

No native probe rebuild is required. Keep the v0.31.4 native probe DLL.

## Expected log

```text
[StereoRig] CircleRet subtree isolated on capture layer 30; objects=...
Ancestors remain on their original layers.
```
