# v0.3.1 Camera Probe fix

This update removes the timer-based probe because `Update()` was not reliably invoked in the injected IL2CPP behaviour.

## Replace

- `Core/RuntimeBehaviour.cs`
- `Config/ModConfig.cs`
- `PluginInfo.cs`

Keep the existing:

- `Diagnostics/CameraProbe.cs`
- `Diagnostics/SceneExplorer.cs`
- `Diagnostics/RuntimeDiagnostics.cs`

## Build and install

1. Rebuild the solution.
2. Confirm `1 succeeded, 0 failed`.
3. Copy the new `MortuaryAssistantVR.dll` to:

```text
BepInEx/plugins/MortuaryAssistantVR/
```

4. Overwrite the old DLL.

## Test

1. Start the game.
2. Load a playable shift.
3. Wait until you can move.
4. Walk around briefly.
5. Exit normally.
6. Open `BepInEx/LogOutput.log`.

The log should start with:

```text
Loading [MortuaryAssistantVR 0.3.1]
```

Search for:

```text
Running Camera Probe immediately
=== Camera Probe begin
[CameraProbe]
=== Camera Probe end
```

Upload the resulting log.
