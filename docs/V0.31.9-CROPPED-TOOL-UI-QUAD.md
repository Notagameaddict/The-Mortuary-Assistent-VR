# v0.31.9 — Crop residual tool-UI edge artifacts

v0.31.8 reported:

```text
Suppressed 0 CanvasRenderer(s) attached directly to InGameUI root
```

so the remaining black/blue regions are not caused by a root Graphic.

The useful parts now work:

- CircleRet is sharp;
- cursor is visible;
- selection works everywhere;
- most of the stereo world is visible correctly behind the menu.

The remaining artifact is limited to peripheral parts of the full 2560x1440
tool-UI quad.

v0.31.9 keeps the Unity render and input space at the original 2560x1440, but
the OpenXR composition layer displays only a conservative central rectangle:

```text
x = 480 .. 2079
y = 195 .. 1244
size = 1600 x 1050
```

This is deliberately done only in `XrSwapchainSubImage.ImageRect`. The actual
RenderTexture, Windows cursor position and game input remain full-resolution,
so item selection behavior is unchanged.

The physical OpenXR quad height is recalculated from the crop aspect ratio.

## Replace

- `PluginInfo.cs`
- `XR/OpenXrNativeBackend.cs`
- `XR/StereoCameraRig.cs`

No native PresentHookProbe rebuild is required.

If any menu item gets cut off, the crop can be widened in the next revision
without touching input handling.
