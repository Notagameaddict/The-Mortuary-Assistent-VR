# v0.27.1 — Scene reload and interaction stability

The v0.27 log revealed two separate problems.

## 1. Double image after returning to MainMenu and loading Mortuary again

The second Mortuary load creates a new XR rig and new stereo textures, but
`HeadTrackingPatch` still retained the managed `Transform` wrapper from the
first scene. Unity had already destroyed that native Transform.

Because the code used C# `is null`, Unity's overloaded destroyed-object null
check was bypassed. The log then produced thousands of:

```text
UnityEngine.Transform.set_localRotation
System.NullReferenceException
```

v0.27.1 resets all scene-specific head-tracking state on every scene boundary
and uses Unity-aware `== null` checks.

## 2. Pickup reliability after using the mortuary PC

v0.27 treated any visible Unity cursor as a request for the desktop UI
fallback. That was too broad and could interfere with ordinary gameplay
interaction states.

The cursor now triggers fallback only while the raycast is targeting the
mortuary computer (`CompWall`, computer/monitor-like parent names). Pause mode
still always uses fallback.

A small Windows left-click fallback is also restored for world objects. If the
normal game click misses a pickup/use action, the mod searches the targeted
object hierarchy for a parameterless `Pickup`, `PickUp`, `Take`, `Use`, or
`Interact` method. Doors and the mortuary computer are excluded to avoid double
activation.

## Replace

- `PluginInfo.cs`
- `Core/RuntimeBehaviour.cs`
- `XR/HeadTrackingPatch.cs`
- `XR/InteractionPromptDetector.cs`
- `XR/StereoCameraRig.cs`

No native probe rebuild is required.

## Expected second Mortuary load

```text
[HeadTracking] Scene tracking state reset.
[HeadTracking] XR head transform found.
[HeadTracking] Position baseline captured: ...
```

There should be no repeated `Transform.set_localRotation` exceptions.

## Expected PC behavior

```text
[StereoRig] UI fallback active; paused=False, cursorVisible=True, computerTarget=True.
```

After leaving the PC interface, stereo should return without affecting normal
pickup interactions.
