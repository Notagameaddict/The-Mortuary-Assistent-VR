# v0.31.13 — build-safe zero-disparity HUD

This reintroduces the v0.31.11 stereo experiment from the clean v0.31.12
baseline, but replaces the complete OpenXR submission method rather than
patching fragments.

The world remains a normal stereo projection layer.

While CircleRet is visible, the same UI swapchain image is submitted twice:

- one quad visible only to the left eye;
- one quad visible only to the right eye.

The left/right quads are offset by +/- 0.032 m in VIEW space. This is intended
to remove the menu's binocular disparity and stop nearby walls/cabinets from
visually competing with it.

The v0.31.10 crop is intentionally unchanged for this test.

Replace:
- PluginInfo.cs
- XR/OpenXrNativeBackend.cs

No native probe rebuild is required.
