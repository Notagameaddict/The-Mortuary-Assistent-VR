# v0.17.4.1 — Remove SEH wrapper from Present callback

MSVC reported:

```text
C2712: Cannot use __try in functions that require object unwinding
```

The workflow builds with `/EHsc`, so the native Present hook may not use
`__try` / `__except` in that function.

This revision removes the native SEH wrapper and calls the callback directly.
The managed callback already catches its own exceptions.

## Replace

- `PluginInfo.cs`
- `native/PresentHookProbe/PresentHookProbe.cpp`

## Build steps

1. Commit and push the native source.
2. Run `Build D3D11 Present Hook Probe` as a new workflow run.
3. Download and replace `MortuaryAssistantVR.PresentHookProbe.dll`.
4. Rebuild the managed solution.
5. Copy the rebuilt `MortuaryAssistantVR.dll`.

Expected native build result:

```text
Success
```
