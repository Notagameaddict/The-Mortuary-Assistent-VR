# v0.8 OpenXR instance creation

This milestone can load the official Khronos OpenXR loader and call `xrCreateInstance`.

It does not create an XR system, D3D11 session, swapchain, or headset pose.

## Replace

- `XR/XrBackendState.cs`
- `XR/OpenXrNativeBackend.cs`
- `PluginInfo.cs`

## Add

- `tools/Build-OfficialOpenXRLoader.ps1`

## Build the official loader

Open PowerShell in the repository and run:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Build-OfficialOpenXRLoader.ps1
```

Requirements:

- Git
- CMake
- Visual Studio C++ build tools

The script is pinned to Khronos tag `release-1.1.62`. It builds the dynamic x64 loader and records its SHA-256.

Copy:

```text
OpenXRLoaderOutput\openxr_loader.dll
```

to:

```text
The Mortuary Assistant\BepInEx\plugins\MortuaryAssistantVR\
```

Do not copy it into `System32`.

## Loader-only test

Keep:

```ini
[XR]
AttemptStartup = false
```

Expected:

```text
Loading [MortuaryAssistantVR 0.8.0]
state=StartupDisabled
```

## Instance test

Close the game and set:

```ini
[XR]
AttemptStartup = true
```

Connect the Quest through Virtual Desktop before starting the game.

Expected:

```text
Calling xrCreateInstance
xrCreateInstance result=0
state=InstanceCreated
```

A non-zero result means instance creation failed. Upload the complete log and return `AttemptStartup` to `false`.

## Safety boundary

This version only creates and later destroys an OpenXR instance. It does not create a graphics session and should not change the game image.
