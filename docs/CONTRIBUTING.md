# Contributing

## Ground rules

- Do not commit game files, generated interop assemblies, logs containing private paths, or proprietary assets.
- Keep pull requests focused on one subsystem or issue.
- Include relevant `LogOutput.log` excerpts when reporting a crash.
- State the game version, BepInEx build, headset, runtime, and connection method.
- Avoid speculative Harmony patches without confirming the target method exists in the current game build.
