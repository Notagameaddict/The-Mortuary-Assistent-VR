# v0.31.7 — Include Canvas root, exclude Rsystem

v0.31.5/v0.31.6 moved only the `CircleRet` subtree to the private capture
layer. The user then saw only the black/blue capture background plus the
cursor, not the actual tool menu.

That result shows the root Canvas must also be visible to the UI camera.
Unity does not submit the child UI correctly when its Canvas root is excluded
by the camera culling mask.

v0.31.7 therefore captures exactly:

```text
InGameUI                 <- Canvas root included
└─ Rsystem               <- deliberately NOT moved to capture layer
   └─ CircleRet          <- included
      └─ all children    <- included
```

This is intentionally different from v0.31.3:

- v0.31.3 included `InGameUI + Rsystem + CircleRet` and could bring in the
  unwanted full-screen black/blue/blur background;
- v0.31.5 included only `CircleRet` and lost the menu itself;
- v0.31.7 includes the Canvas root and CircleRet, but excludes `Rsystem`.

The transparent per-frame RenderTexture clear and visible cursor are retained.

## Replace

- `PluginInfo.cs`
- `XR/StereoCameraRig.cs`

No native probe rebuild is required. Keep the v0.31.4 native probe DLL.

Rsystem remains excluded.
