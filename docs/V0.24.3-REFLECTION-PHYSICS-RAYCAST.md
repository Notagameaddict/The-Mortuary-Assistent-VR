# v0.24.3 — Reflection-based Physics raycast

Visual Studio reported:

```text
CS0246: Collider could not be found
CS0246: RaycastHit could not be found
```

Those types live in `UnityEngine.PhysicsModule.dll`, which is not referenced by
the current project.

This revision avoids adding another compile-time Unity assembly reference. It
locates `UnityEngine.Physics`, `UnityEngine.RaycastHit`, and
`UnityEngine.Collider` from the already loaded game assemblies and calls the
three-argument `Physics.Raycast(Ray, out RaycastHit, float)` overload through
reflection.

## Replace

- `PluginInfo.cs`
- `XR/InteractionPromptDetector.cs`

No native rebuild is required.
