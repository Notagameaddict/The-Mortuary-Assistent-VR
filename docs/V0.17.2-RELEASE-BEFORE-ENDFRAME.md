# v0.17.2 — Release swapchain images before xrEndFrame

v0.17.1 successfully cleared the OpenXR swapchain textures, but `xrEndFrame` returned:

```text
-23
```

That is `XR_ERROR_LAYER_INVALID`.

The acquired swapchain images were still held when the projection layer was submitted. This revision changes the frame order to:

```text
xrAcquireSwapchainImage
xrWaitSwapchainImage
clear texture
xrReleaseSwapchainImage
xrEndFrame with projection layer
```

It also safely releases any images that were acquired before a later eye failed.

## Replace

- `PluginInfo.cs`
- `XR/OpenXrNativeBackend.cs`

No native Present-hook rebuild is required.
