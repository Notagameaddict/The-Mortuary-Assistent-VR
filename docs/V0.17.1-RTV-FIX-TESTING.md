# v0.17.1 — Explicit D3D11 render-target view format

v0.17 reached the projection path but `CreateRenderTargetView` failed with native result `4`.

This revision:

- passes the selected OpenXR DXGI format to the native helper;
- creates the render-target view with an explicit `D3D11_RENDER_TARGET_VIEW_DESC`;
- handles Texture2D, Texture2DMS, and Texture2DArray resources;
- logs the exact HRESULT if view creation still fails;
- reports `TestPatternRendering` only after a projection layer was actually submitted.
