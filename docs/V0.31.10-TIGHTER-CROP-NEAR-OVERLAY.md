# v0.31.10 — Tighter crop + foreground stereo depth

Two remaining issues were reported after v0.31.9:

1. the residual black/blue artifact was improved but still large on the right;
2. close to a wall/cabinet, the tool-selection window appeared to disappear
   into the geometry.

The log confirms the UI capture remains stable and, during one close-wall test,
the world interaction ray saw `WALL` at about 1.09 m immediately before
CircleRet opened. The tool UI quad in v0.31.9 was also placed at 1.10 m.

That creates a stereo-depth conflict: the wall and UI are at essentially the
same virtual depth. OpenXR still composites the quad after the projection
layer, but binocular depth cues can make the UI feel embedded in the wall.

## Changes

### Tighter asymmetric crop

Old:

```text
x=480 y=195 width=1600 height=1050
```

New:

```text
x=620 y=255 width=1220 height=900
```

This removes substantially more of the right-hand residual area.

### UI moved closer in stereo depth

Old:

```text
distance = 1.10 m
width = 1.20 m
```

New:

```text
distance = 0.42 m
width = 0.458 m
```

Width is scaled with distance, so the menu keeps approximately the same
angular size while gaining much nearer binocular depth. It should therefore
read clearly in front of nearby walls and cabinets.
