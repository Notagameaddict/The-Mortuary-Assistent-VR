# v0.24.1 — Fix native HLSL source strings

The v0.24 native build failed because several adjacent C++ string fragments in
the generated hand-indicator shader were missing separators. MSVC therefore
parsed HLSL tokens such as `float`, `float2`, `step`, and `length` as C++ code.

This revision replaces both pixel-shader definitions with C++ raw string
literals:

```cpp
R"HLSL(
    // HLSL source
)HLSL"
```

It also renames the HLSL variable `cross` to `cursorCross` for clarity.

## Replace

- `PluginInfo.cs`
- `native/PresentHookProbe/PresentHookProbe.cpp`

No managed code changes are required beyond the version bump.

Run a new `Build D3D11 Present Hook Probe` workflow after committing.
