# v0.17.3.1 — LateUpdate render loop

De Unity 2021.2 IL2CPP-referenties van dit project bevatten geen
`Application.onBeforeRender`. Daarom gaf v0.17.3 fout CS0117.

Deze revisie gebruikt in plaats daarvan een publieke Unity-callback:

```csharp
public void LateUpdate()
```

## Vervangen

- `PluginInfo.cs`
- `Core/RuntimeBehaviour.cs`

Laat de overige v0.17.3-bestanden staan. De native probe hoeft niet opnieuw
gebouwd te worden.
